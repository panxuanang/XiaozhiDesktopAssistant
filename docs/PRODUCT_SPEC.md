# 小智电脑助手 V1 产品定义

## 对外卖点

一句话：**让你的小智会用电脑。**

五个核心演示：

1. “给张总发微信，说我十分钟后到。”
2. “帮我写一份会议通知，做成 Word 放桌面。”
3. “分析这份销售 Excel，找出下降最大的门店。”
4. “打开这个网页，总结一下主要内容。”
5. “帮我找到昨天下载的合同。”

## 商业版原则

- 客户不装 Python、不编辑 YAML、不碰命令行
- 自己填写 API，供应商可替换
- 尽量用本地计算/结构化读取，降低 Token 成本
- OCR 是兜底，不是主路径
- 高风险动作必须确认
- 每个动作有日志
- 断线自动重连
- 客户端能自检
- 自动更新可回滚（当前工程提供下载/哈希骨架，回滚需结合发布服务完善）

## 后续优先增强

1. 本地弹窗级确认中心（替代只靠模型确认）
2. 扫描 PDF 逐页 OCR
3. 浏览器扩展/Native Messaging，用用户现有浏览器登录态而非独立 profile
4. 微信版本适配层与自动 UI 特征检测
5. 操作录制/回放与失败恢复
6. 自动更新签名、灰度和回滚
7. 企业隐私模式/本地模型
